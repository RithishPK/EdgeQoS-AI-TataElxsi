Technical details

Only IPv4 traffic routed through the Pi hotspot is counted. Devices on the home router and same-network peer traffic can bypass the Pi. Traffic totals are observed IP packet bytes, not a billing meter. Classification uses flow metadata, not packet payload contents.

Refreshes every 2 seconds · Mode changes preserve traffic totals · Allow 10 seconds after switching for the rate window to settle
